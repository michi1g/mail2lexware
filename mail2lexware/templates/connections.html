  1. {% if has_credentials %}{{ icon('check', 'bold') }}{% else %}1{% endif %}

    OAuth-Client hochladen

    Du brauchst einen OAuth-Client vom Typ „Desktop-App“ aus der Google Cloud Console. Die heruntergeladene credentials.json lädst du hier hoch.

    {{ icon('caret-right', 'bold') }}So erstellst du den OAuth-Client
    1. Öffne die Google Cloud Console und lege ein Projekt an, zum Beispiel „Workspace Lexware“. Mit dem Workspace-Konto anmelden, dessen Postfach durchsucht werden soll.
    2. Gmail API aktivieren. Ohne diesen Schritt schlägt jeder Zugriff fehl. Öffne die Gmail API im Projekt und klicke auf „Aktivieren“.
    3. Richte den OAuth-Zustimmungsbildschirm ein. Wähle bei Workspace den Nutzertyp „Intern“. Dann läuft der Zugriff dauerhaft und Google muss die App nicht prüfen.
    4. Erstelle unter Anmeldedaten über „Anmeldedaten erstellen“ eine „OAuth-Client-ID“ vom Typ „Desktop-App“ und lade die JSON-Datei herunter.

    Das Tool fragt nur den Zugriff gmail.modify an: Lesen und Labels setzen, kein Senden und kein Löschen.
